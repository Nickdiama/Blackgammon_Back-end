# Περιγραφή Παιχνιδιού

Το τάβλι παίζεται ως εξής: Το τάβλι παίζεται σε πίνακα (ταμπλώ). Ο πίνακας χωρίζεται σε τέσσερις περιοχές, με κάθε περιοχή να περιλαμβάνει έξι θέσεις, συνολικά δηλαδή 24 θέσεων, που έχουν κατά παράδοση τριγωνικό σχήμα. Κάθε παίκτης πριν παίξει ρίχνει τα δύο ζάρια· ειδικούς κύβους με αριθμητικές ενδείξεις σε κάθε έδρα, που αντιστοιχούν στους αριθμούς από ένα ως έξι.

Για την πρώτη ζαριά του παιχνιδιού υπάρχουν δυο παραλλαγές:

1. ο παίκτης που αποφασίστηκε να παίζει πρώτος ρίχνει τα δύο ζάρια.
2. οι παίκτες ρίχνουν από ένα ζάρι· αν φέρουν το ίδιο αποτέλεσμα ξαναρίχνουν ώσπου να μην φέρουν το ίδιο αποτέλεσμα.

Το δεύτερο σύστημα συχνά χρησιμοποιείται και για να αποφασιστεί ποιος παίζει πρώτος. Θα πρέπει βέβαια να έχει προαποφασιστεί αν η ζαριά που μένει κάτω θα μετρήσει και ως πρώτη ή όχι (στη παρούσα υλοποίηση, η ζαρία αυτή δεν μετράει για πρώτη). Κάθε παίκτης έχει μια περιοχή εκκίνησης και η απέναντί της περιοχή είναι η περιοχή μαζέματος του παίκτη. Τα πούλια τού παίκτη κινούνται κυκλικά από την περιοχή εκκίνησης στην περιοχή μαζέματος. Όταν ένας παίκτης έχει όλα του τα πούλια στην περιοχή μαζέματος, τότε του επιτρέπεται να ξεκινήσει το μάζεμα.

Το πλακωτό είναι ένα από τα βασικά παιχνίδια του ταβλιού. Βασικό χαρακτηριστικό του παιχνιδιού είναι η δυνατότητα αιχμαλωσίας ("πλακώματος") εχθρικών πουλιών ώστε να εμποδίζεται η κίνησή τους για όσο διάστημα βρίσκονται πλακωμένα (εξ ου και το όνομα του παιχνιδιού).

Οι κανόνες του πλακωτού είναι οι ακόλουθοι: 
Ένας παίκτης έχει πόρτα σε μια θέση όταν

1. Έχει δυο η περισσότερα πούλια σε αυτήν
2. Έχει πλακώσει αντίπαλο πούλι σε αυτήν

Οι πόρτες λειτουργούν ως εμπόδιο στην κίνηση του αντιπάλου αλλά και ως "πατήματα" για να τοποθετεί ένας παίκτης με ασφάλεια τα πούλια του.

Αν ο ένας παίκτης έχει μαζέψει όλα τα πούλια του πριν προλάβει ο αντίπαλος να μαζέψει έστω και ένα πούλι τότε το παιχνίδι είναι διπλό.

## Στήσιμο
Ο κάθε παίκτης έχει την περιοχή εκκίνησής του μπροστά του (κάτω δεξιά ή κάτω αριστερά) και απέναντί της βρίσκεται η περιοχή μαζέματος. Κινείται κανονικά από την περιοχή εκκίνησης στην περιοχή μαζέματος κυκλικά (ωρολογιακά ή αντιωρολογιακά). Η περιοχή εκκίνησης του ενός παίκτη είναι η περιοχή μαζέματος του άλλου.

## Πλάκωμα
(ή πιάσιμο)
Όταν ένα πούλι βρίσκεται μόνο του σε μια θέση (δεν αποτελεί πόρτα) ο αντίπαλος έχει το δικαίωμα να κινήσει σε αυτήν την θέση πούλι του πλακώνοντας το εχθρικό πούλι. Η θέση γίνεται πόρτα του παίκτη που πλακώνει και ο οποίος έχει την δυνατότητα να τοποθετεί όσα πούλια ακόμα θέλει σε αυτήν. Το πλακωμένο πούλι δεν έχει το δικαίωμα να κινηθεί από την θέση του. Τα πούλια που το πλακώνουν είναι ελεύθερα να κινηθούν από την θέση αυτή αν όμως φύγουν όλα από τη θέση τότε το πούλι ξεπλακώνεται και είναι ελεύθερο να κινηθεί κανονικά.

Ο παίκτης έχει το δικαίωμα να ξεκινήσει το μάζεμα όταν όλα τα πούλια του βρίσκονται στην περιοχή μαζέματος και ο αντίπαλος του δεν έχει κανένα πλακωμένο πούλι του παίκτη . Αν κατά τη διάρκεια του μαζέματος από τον παίκτη, ο αντίπαλος πλακώσει κάποιο πούλι ή πούλια του παίκτη, τότε ο παίκτης σταματάει το μάζεμα μέχρι να ξεπλακώσει ο αντίπαλος τα πούλια του παίκτη.

Στο πλακωτό όπως και στις πόρτες και το φεύγα είναι υποχρεωτική η ολοκλήρωση μιας ζαριάς εφ΄ όσον αυτό είναι εφικτό.

## Πιάσιμο της μάνας
Όταν ένας παίκτης πλακώσει την μάνα του αντιπάλου (το τελευταίο πούλι που θα βρεθεί μόνο του στην θέση 1 (ή 24) από την σκοπιά αυτού που πλακώνει) τότε το παιχνίδι χάνεται διπλό.

# Η βάση δεδομένων 
Η βάση μας κρατάει τους εξής πίνακες και στοιχεία: 
Πίνακας 'board': position (οι θέσεις του ταμπλό 0-25 με τις θέσεις 0 και 25 να είναι εκτός ταμπλό και 1-24 εντός ταμπλό), w_count, b_count (μετριτές άσπρων και μαύρων πούλιων ανα θέση αντίστοιχα), top_color (δείχνει το χρώμα του πούλιου που είναι από πάνω σε περίπτωση πλακώματος ή αν υπάρχουν δύο και πάνω πούλια ίδιου χρώματος σε αυτή τη θέση).

Πίνακας 'game_status': status (κρατάει τη κατάσταση που βρίσκεται το παιχνίδι), p_turn (ποιανού σειρά είναι να παίξει), start_dice_w, start_dice_b (ζάρια για να αποφασιστεί ποιός παίζει πρώτος, ένα για κάθε παίκτη), dice1, dice2, dice3, dice4 (τα ζάρια του παιχνιδιού, τα ζάρια dice3 και dice4 συμπληρώνονται σε περίπτωση διπλής ζαρίας), double_count (μετριτής παιξίματος διπλής ζαριάς), result (ο νικητής της παρτίδας), score (1 για μονό παιχνίδι, 2 για διπλό), last_change (κρατάει την στιγμή της τελευταίας αλληλεπίδρασης που έγινε στο παιχνίδι).

Πίνακας 'players': username (όνομα χρήστη), piece_color (τα πούλια του χρήστη), token (το μοναδικό αναγνωριστικό του χρήστη), last_action (κρατάει την στιγμή της τελευταίας αλληλεπίδρασης του χρήστη).

procedure 'clean_board': αρχικοποιεί το παιχνίδι.

procedure 'move_piece': κάνει την κίνηση του πούλιου στη βάση δεδομένων.

Η εφαρμογή αναπτύχθηκε μέχρι το σημείο back-end (δημιουργία βάσης δεδομένων, PHP API), δεν υπάρχει front-end / διεπαφή χρήστη.

# Περιγραφή API

## Methods


### Board
#### Ανάγνωση Board

```
GET /board/
```

Επιστρέφει το [Board](#Board).

#### Αρχικοποίηση Board
```
POST /board/
```
Αρχικοποιεί το Board, δηλαδή το παιχνίδι. Γίνονται reset τα πάντα σε σχέση με το παιχνίδι.
Επιστρέφει το [Board](#Board).

### Piece

#### Μεταβολή Θέσης Πούλιου

```
PUT /board/piece/:from/:to
```

Κάνει την κίνηση του πιονιού από την θέση from στην νέα θέση to. Προφανώς ελέγχεται η κίνηση αν είναι νόμιμη καθώς και αν είναι η σειρά του παίκτη να παίξει με βάση το token.
Επιστρέφει τα στοιχεία από το [Board](#Board-1).

### Dice

#### Start

```
GET /board/dice/start
```

Ρίχνει ένα ζάρι για κάθε παίκτη, ανάλογα με το token το οποίο περνάει μέσα από τα headers, για να αποφασιστεί ποιός παίζει πρώτος. Γίνεται έλεγχος αν ο παίκτης είναι υπαρκτός με βάση το token, αν έχει πραγματοποιηθεί ρίψη προηγουμένως από τον παίκτη και αν τυχόν οι δύο παίκτες έφεραν το ίδιο ζάρι, για να ξαναρίξουν. Μετά τη ρίψη, εμφανίζεται το ζάρι που έφερε ο παίκτης και μήνυμα αναμονής άμα ο άλλος παίκτης δεν έχει ρίξει ή ποιός παίζει πρώτος, αν έριξε δεύτερος. Ταυτόχρονα, και τα δύο ζάρια αποθηκεύονται στη βάση.

#### Roll

```
GET /board/dice/roll
```

Ρίχνει τα ζάρια με τα οποία ο παίκτης θα κάνει τις κινήσεις του. Για να μπορέσει να γίνει η κλήση, πρέπει το token του παίκτη να περαστεί μέσα από τα headers. Γίνονται έλεγχοι αν μπορεί να πραγματοποιηθεί η ρίψη και στη συνέχεια τα ζάρια αποθηκεύονται στη βάση.

### Player

#### Ανάγνωση στοιχείων παίκτη
```
GET /player/:p
```

Επιστρέφει τα στοιχεία του παίκτη p ή όλων των παικτών αν παραληφθεί. Το p μπορεί να είναι 'B' ή 'W'.

#### Καθορισμός στοιχείων παίκτη
```
PUT /player/:p
```
Json Data στο body:

| Field             | Description                 | Required   |
| ----------------- | --------------------------- | ---------- |
| `username`        | Το username για τον παίκτη p. | yes        |


Επιστρέφει τα στοιχεία του παίκτη p και ένα token. Για να γίνει η επιλογή χρώματος, απαραίτητη προϋπόθεση είναι να δοθεί το p (είτε W, είτε Β). Το token πρέπει να το χρησιμοποιεί ο παίκτης καθόλη τη διάρκεια του παιχνιδιού.

## Entities


### Board
---------

Το board είναι ένας πίνακας, ο οποίος στο κάθε στοιχείο έχει τα παρακάτω:


| Attribute                | Description                                  | Values                              |
| ------------------------ | -------------------------------------------- | ----------------------------------- |
| `position`                      | Οι θέσεις του ταμπλό              | 0..25                                |
| `w_count`                      | Μετριτής άσπρων πούλιων ανα θέση              | 0..15                                |
| `b_count`                | Μετριτής μαύρων πούλιων ανα θέση                     | 0..15                            |
| `top_color`            | Δείχνει το χρώμα του πούλιου που είναι από πάνω σε περίπτωση πλακώματος ή αν υπάρχουν δύο ή περισσότερα πούλια ίδιου χρώματος σε αυτή τη θέση                       | 'B','W', null                       |


### Players
---------

O κάθε παίκτης έχει τα παρακάτω στοιχεία:


| Attribute                | Description                                  | Values                              |
| ------------------------ | -------------------------------------------- | ----------------------------------- |
| `username`               | Όνομα παίκτη                                 | String                              |
| `piece_color`            | To χρώμα που παίζει ο παίκτης                | 'B','W'                             |
| `token  `                | To κρυφό token του παίκτη. Επιστρέφεται μόνο τη στιγμή της εισόδου του παίκτη στο παιχνίδι | HEX |
| `last_change  `                | Η στιγμή της τελευταίας αλληλεπίδρασης του χρήστη | timestamp |


### Game_status
---------

H κατάσταση παιχνιδιού έχει τα παρακάτω στοιχεία:


| Attribute                | Description                                  | Values                              |
| ------------------------ | -------------------------------------------- | ----------------------------------- |
| `status  `               | Κατάσταση             | 'not active', 'initialized', 'started', 'ended'     |
| `p_turn`                 | To χρώμα του παίκτη που παίζει        | 'B','W',null                              |
| `start_dice_w`                 | Αρχικό ζάρι του παίκτη με τα άσπρα πούλια        | 1..6                             |
| `start_dice_b`                 | Αρχικό ζάρι του παίκτη με τα μαύρα πούλια        | 1..6                             |
| `dice1`                 | Ζάρι        | 1..6                             |
| `dice2`                 | Ζάρι        | 1..6                             |
| `dice3`                 | Ζάρι (συμπληρώνεται σε περίπτωση 'διπλής')        | 1..6                              |
| `dice4`                 | Ζάρι (συμπληρώνεται σε περίπτωση 'διπλής')        | 1..6                              |
| `double_count`                 | Μετριτής παιξίματος σε 'διπλή'        | 0..4                            |
| `result`                 |  To χρώμα του παίκτη που κέρδισε |'B','W',null                              |
| `score`                 | Μονό ή διπλό παιχνίδι        | 1, 2                              |
| `last_change`            | Τελευταία αλλαγή/ενέργεια στην κατάσταση του παιχνιδιού         | timestamp |
